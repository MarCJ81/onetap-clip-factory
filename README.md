# 원탭 클립 팩토리 (OneTap Clip Factory) · v2

**영상 하나 → 세로 숏폼 클립 여러 개. 블로그 글 하나 → 5장면 카드 쇼츠.**
강의·브이로그·게임·인터뷰 녹화를 넣으면 죽은 초를 지우고, 장면 컷을 찾아 클립으로 나누고,
9:16으로 리프레임한 뒤 자막까지 얹어 **실제 H.264 MP4 파일**로 뽑습니다.
블로그 URL(또는 붙여넣은 본문)을 넣으면 5장면 대본과 화면 자막을 만들어 **카드형 9:16 MP4**로 뽑습니다.

- **모드 A · 영상 자동컷**: 무음 자동 컷 → 9:16 스마트 크롭(피사체/중앙/블러 배경) → 대본 기반 카라오케 자막 → AI 제목·훅 → MP4. **원버튼**으로 전 과정을 한 번에.
- **모드 B · 블로그 쇼츠**: URL 읽기(무료 읽기 프록시) → 5장면 대본(AI/규칙) → 캔번즈 줌·팬 카드 → 자막·BGM 덕킹 → 9:16 MP4. 더빙은 무음/브라우저 음성/Fish Audio 3단.

- 자막(.srt/.vtt)을 넣으면 **AI가 스토리·재미·반전 구간을 골라** 클립 후보로 만들고,
  각 구간에 **원본 대사를 베끼지 않은 '해설 자막'(새 해석·요약·포인트)** 을 함께 씁니다.
- 22호기 **원탭 숏폼 스튜디오**(대본 → 새 숏폼 제작)와 역할이 다릅니다. 이쪽은 **이미 찍어 둔 긴 원본을 잘라 쓰는 공장**입니다.
- 라이브: <https://marcj81.github.io/onetap-clip-factory/>
- 가입 없음 · 서버 업로드 없음 · API 키 없이 무료 모드 100% 동작.
- Pro(선택): OpenAI · Gemini · Claude · 자체 서버를 연결하면 같은 버튼이 더 좋은 제목·훅·해설을 만듭니다.

## 2. 여섯 단계

| 단계 | 하는 일 | 조절 |
|---|---|---|
| 01 STORY | **자막(.srt/.vtt) 넣기 → AI 스토리·재미·반전 구간 3~6개 추천 → 한 번에 클립으로 담기**. 각 구간에 해설 자막까지 생성 | 추천 개수 3~6, 구간 길이 4~30초 |
| 02 SOURCE | MP4·WebM·MOV 드래그&드롭, 또는 **데모 VOD 생성**(32초, Canvas+WebAudio) | 유튜브는 yt-dlp 명령 1클릭 복사(영상+자막 동시) |
| 03 DETECT | 20ms 단위 음량으로 **죽은 초** 감지, 표본 프레임 히스토그램으로 **장면 컷** 후보 | 무음 임계치·최소 무음·말소리 여백·컷 감도, 클립 길이·개수 |
| 04 REFRAME | 열별 **피부톤 + 움직임 + 중앙 가중**으로 9:16 크롭 중심을 추적, 속도 제한 곡선으로 부드럽게 이동 | 피사체/움직임/중앙, 부드러움, 줌 1~1.6× |
| 05 CAPTION | SRT/VTT 불러오기, 타임코드 인라인 편집, 쇼츠 스타일 4종, **해설+대사/해설만/대사만** | 옐로 임팩트 · 클린 화이트 · 블랙 박스 · 키커 라임 |
| 06 RENDER | 클립별 순차 렌더, 진행률·용량·소요 시간 표시, 개별 MP4 / ZIP | 해상도·fps·자막 포함 |

### 데모 VOD
외부 파일을 받지 않습니다. 누르는 순간 Canvas로 장면 5개(스튜디오·화면 공유·인터뷰·B-롤·아웃트로)와
움직이는 피사체를 그리고, OfflineAudioContext로 말소리 5블록과 **무음 6구간**을 합성해
mediabunny로 H.264 MP4로 인코딩합니다. 그래서 무음 제거·장면 컷·추적·자막·렌더를 한 번에 시험할 수 있습니다.

## 2-B. V2 자동 모드 (2026-11 추가)

### A. 원버튼 자동 쇼츠 (영상)
왼쪽 레일 맨 위 **AUTO** 패널에서 세로 크롭·무음 길이·클립 수만 고르고 **원버튼으로 쇼츠 만들기**를 누르면:

1. 원본 분석(소리 봉투 + 장면 표본)
2. 설정한 길이 이상 무음 컷 (기본 0.6초, `minSilenceMs`로 그대로 전달)
3. 9:16 크롭 — `subject`(피부톤·움직임 추적) / `center` / **`blur`**(원본을 9:16으로 채워 흐리게 깔고 안 잘린 원본을 중앙에)
4. 대본을 붙여넣었다면 `scriptToCues`가 **말소리 구간에 글자 수 비례로 배분**해 자막 타임코드를 만듭니다(자막 파일이 없어도 됨)
5. 점수 상위 N개 클립을 골라 제목·훅 생성 — **내 Gemini 키 → Pro → 무료 맛보기 → 규칙** 순서, 실패하면 즉시 다음 단계로
6. 선택 클립을 순서대로 MP4 렌더(+ ZIP)

각 단계 상태는 패널의 5단계 목록에 표시되고, 결과는 기존 클립 카드·렌더 큐에서 그대로 다듬을 수 있습니다.

### B. 블로그 → 카드 쇼츠

| BGM | 내장 합성(`calm`/`beat`, OfflineAudioContext) 또는 내 파일. 말하는 구간에서 볼륨을 줄이는 덕킹 | BGM 없이 렌더 |
| 렌더 | 9:16 캔버스 → H.264 MP4. 미리보기와 **같은 `drawFilmFrame`** 을 쓰므로 WYSIWYG | WebCodecs 없으면 렌더 버튼 비활성 + 이유 표시 |

### C. GeminiCore (`engines/gemini-core.js`)
- `x-goog-api-key` 헤더로 호출 (`?key=` 쿼리보다 키가 로그에 덜 남음)
- 모델 폴백: `gemini-2.5-flash → gemini-2.0-flash → gemini-2.5-flash-lite → gemini-1.5-flash`
- 429·500·503은 0.8초 쉬고 같은 모델 한 번 더, 그 뒤 다음 모델
- 404(모델 없음)·400은 즉시 다음 모델, 401/403은 키 오류로 중단
- 키는 sessionStorage 기본, “이 브라우저에 기억”을 고를 때만 localStorage
- JSON 모드(`responseMimeType: application/json`) + 코드펜스 제거

### D. Fish Audio 더빙 (`engines/tts.js`)
- `POST https://api.fish.audio/v1/tts`, `Authorization: Bearer`, `model: s2.1-pro-free|s2.1-pro` 헤더, `{text, reference_id, format:"mp3"}`
- 브라우저 직접 호출은 CORS로 막히므로 **무료 공용 프록시**(`https://onetap-fish-proxy.onetap-ai.workers.dev`, Cloudflare Worker)를 기본으로 거침(`DEFAULT_PROXY`). 프록시는 키를 저장하지 않고 `Authorization`·`model` 헤더와 본문을 `api.fish.audio/v1/tts`로 그대로 넘김
- 주소 칸에서 다른 프록시로 바꿀 수 있고, 비우면 직접 호출(대부분 CORS로 막힘). Worker 소스는 `infra/fish-proxy-worker/`
- 받은 mp3는 `decodeAudioData` → 장면 시작 +140ms에 배치, 겹치면 장면 길이가 늘어남

## 3. 실제 계산 방식

### 무음(죽은 초)
- Web Audio `decodeAudioData` → 채널별 20ms RMS 봉투 → dBFS.
- 기본 임계치 −38dB, 최소 무음 380ms, 말소리 여백 90ms.
- 임계치 아래가 최소 길이 이상 이어지면 제거 대상. 여백은 무음 쪽으로만 밀어 말끝을 보존합니다.
- 남긴 구간이 떨어져 있으면 클립은 **여러 원본 구간을 이어 붙인 하나의 출력**이 됩니다. 렌더·자막 매핑 모두 이 타임라인을 기준으로 계산합니다.

### 장면 컷
- 표본 프레임(최대 260개)을 128×72로 줄여 16구간 밝기 히스토그램 + 밝기 변화량을 계산.
- 중앙값 + 2.6×MAD 로 적응 임계치를 잡고, 650ms 이내 중복은 가장 강한 것만 남깁니다.
- 클립 경계는 1.3초 이내의 컷 후보에 붙습니다(스냅).

### 9:16 리프레임
- 클립마다 6fps로 열(column) 지도를 만듭니다. 열마다 피부톤 픽셀 비율, 이전 표본 대비 움직임, 중앙 가중치를 합성.
- 가장 강한 열 주변 ±8열의 가중 중심을 크롭 중심으로 사용. 특징이 없으면 중앙으로 복귀.
- `buildCurve`가 지수 평활 + 데드존 + 표본당 최대 이동(0.055)으로 카메라 팬을 만듭니다. 순간 이동 없이 따라갑니다.
- 크롭 사각형은 원본 비율과 9:16을 비교해 가로/세로 중 필요한 쪽만 잘라 냅니다. 줌은 크롭을 좁힙니다.

### 렌더
- `CanvasSource`(H.264) + `AudioBufferSource`(AAC, 없으면 Opus) → `Mp4OutputFormat`.
- WebCodecs가 없는 브라우저에서는 렌더 버튼이 비활성되고 이유를 표시합니다(분석·미리보기는 계속 동작).
- 프레임은 원본을 `seek`해 그립니다. 무음이 빠진 구간은 `sourceTimeAt()`으로 매핑합니다.
- 자막은 미리보기와 **같은 함수**로 그려 WYSIWYG를 보장합니다.

### 스토리·재미 구간
- 자막 큐를 `[시작-끝] 대사` 줄로 만들어 AI에 보냅니다. 무료 맛보기는 프롬프트 2,000자 제한이 있어
  `compactCues`가 **균등 간격으로 솎아 내고** 시간 범위는 그대로 남깁니다.
- 응답은 `[{startSec, endSec, title, hook, reason, hashtags, score, commentaryCues}]` 하나. 코드펜스·설명·한글 키·ms 단위가 섞여 와도 `parseStoryJSON`이 읽어 냅니다.
- 검증: 영상 길이로 클램프, 3초 미만 폐기, 60% 이상 겹치는 구간 제거, 최대 6개, 시간 순 정렬.
- **AI가 없거나 429·네트워크 실패면 로컬 규칙**이 같은 모양으로 답합니다. 질문·숫자·반전·감정·핵심 표현의
  신호 점수 + 발화 밀도 + 길이 적합도로 후보 창을 점수화하고, 겹치는 창을 걷어 내며 고릅니다.
  화면에 `로컬 규칙(자막 휴리스틱)`이라고 분명히 적고, 무료 AI 한도로 막힌 경우 Pro 연결 버튼을 띄웁니다.
- 고른 구간은 `segmentsToClips`로 **기존 클립과 똑같은 모양**(ranges·durationMs·score·title·hook)이 됩니다.
  무음이 빠진 keep 구간에 맞춰 ranges를 다시 계산하므로 추적·자막 매핑·렌더가 그대로 호환됩니다.
  이미 있는 스토리 클립과 50% 이상 겹치면 다시 담지 않고, 담은 구간과 겹치는 자동 클립은 **지우지 않고 선택만 해제**합니다.

### AI 해설 자막(새 해석 자막)
- 각 구간마다 `commentaryCues: [{offsetSec, endOffsetSec, text}]` 2~4줄을 AI가 씁니다.
  프롬프트에 "원본 대사를 베끼지 말고 새로 쓴 해석·설명으로"라고 명시하고, 첫 줄은 상황 요약, 가운데는 핵심 포인트, 마지막은 한 줄 해석이 되게 지시합니다.
- 로컬 폴백도 2~4줄을 만듭니다. 질문/숫자/반전/감정 신호로 도입 문장을 고르고, 조사를 떼어 낸 핵심 낱말로
  "핵심은 '…'" · "한 줄 정리: …"를 만듭니다. 복사가 아니라 자막 구조에서 뽑은 **초안**이라 화면에 그렇게 표시합니다.
- 편집: 클립 시트의 **AI 해설 자막** 패널에서 시간·문장을 고치고 줄을 더하거나 지울 수 있습니다. 모양은 배지/외곽선 2종.
- 배치: `captionBands` 하나가 대사·해설 두 층의 세로 밴드를 계산합니다(해설은 위, 대사는 아래, 최소 간격 유지).
  미리보기와 MP4 렌더가 **같은 함수**로 그리므로 WYSIWYG입니다.

## 4. 솔직한 한계

- **얼굴 인식 모델은 넣지 않았습니다.** 피부톤·움직임 추적은 가볍고 빠르지만, 얼굴이 작거나 피부색이 배경과 비슷하면 중앙으로 돌아갑니다.
- **자동 음성 인식(ASR)은 없습니다.** 쓰던 SRT/VTT를 올리거나 직접 입력하세요. 자동 자막을 넣으면 모델 파일(수 MB)을 로컬에 넣어야 해서 이번 범위에서 제외했습니다.
- **AI가 고른 구간과 해설은 초안입니다.** 자막에 없는 사실을 만들지 않도록 지시하지만, 모델은 틀릴 수 있습니다. 렌더 전에 카드에서 제목·해설을 확인하세요. AI를 안 쓰면 로컬 규칙이 문장을 만들며, 이때는 화면에 `로컬 규칙`으로 표시됩니다.
- **해설 자막은 대사 자막과 자리를 나눕니다.** 해설은 위쪽 밴드, 대사는 원래 위치(아래/가운데)에 그립니다. 해설만 고르면 대사는 굽지 않습니다.
- 자동 음성 인식(ASR)은 없습니다. 그래서 **자막이 없으면 스토리 추천도 해설도 만들 수 없습니다**(제목·훅만 수동/AI로 가능).
- 장면 컷은 표본 기반이라 서서히 밝아지는 구간은 놓칠 수 있습니다.
- 유튜브 링크는 브라우저에서 직접 받을 수 없습니다(CORS·약관). yt-dlp로 받은 파일을 끌어다 놓으세요.
- 아주 긴 영상(1시간 이상)은 프레임 표본을 260개로 제한합니다. 파형은 전체를 계산합니다.
- 소리 분석은 파일 전체를 메모리에 올립니다. 1시간이 넘는 원본은 브라우저 메모리가 부족할 수 있습니다.
- AAC 인코더가 없는 브라우저(일부 Linux Chromium)는 MP4 안에 **Opus 오디오**로 저장합니다. 영상은 H.264 그대로입니다.
- 렌더는 원본을 프레임마다 `seek`해 그립니다. 아주 긴 클립(45초)을 1080p로 뽑으면 1~2분 걸릴 수 있습니다.
- 일부 소프트웨어 렌더링 환경(가상 머신·GPU 없는 헤드리스)에서는 큰 화면 전환·스크린샷 순간 렌더러가 불안정할 수 있어, 무거운 블러 효과를 쓰지 않도록 만들었습니다.
- **얼굴 인식 모델은 여전히 없습니다.** 크롭은 피부톤·움직임·중앙 가중 추적이고, 블러 배경은 원본 전체를 살리는 대신 좌우에 여백이 생깁니다.
- **음성 인식(ASR)도 없습니다.** 대본을 붙여넣으면 `scriptToCues`가 말소리 구간에 글자 수 비례로 배분합니다(실제 발음과 수백 ms 차이 가능). Gemini에 오디오를 보내는 전사는 넣지 않았습니다 — 영상·음성 무전송 원칙 때문입니다.
- **블로그 읽기는 공개 읽기 프록시(r.jina.ai)에 의존합니다.** 막는 사이트는 붙여넣기로 넘어가고, 사진은 images.weserv.nl을 거칩니다. 사진이 없는 글이나 프록시가 막힌 환경에서는 그라데이션 카드로 만듭니다.
- **Fish Audio는 브라우저 직접 호출이 CORS로 막힙니다.** 무료 프록시(`onetap-fish-proxy.onetap-ai.workers.dev`)가 기본으로 붙어 있어 키만 있으면 바로 됩니다. 프록시·키 문제로 실패하면 무음 모드로 렌더합니다.
- **AAC가 없는 브라우저(일부 Linux Chromium·헤드리스)는 MP4에 Opus 오디오를 넣습니다.** 영상은 H.264 그대로지만, 일부 플랫폼 업로더는 Opus 오디오를 거부할 수 있습니다. 그런 환경에서는 음소거 렌더 또는 AAC 지원 브라우저를 쓰세요.
- **카드 쇼츠의 장면 길이는 자막 글자 수/더빙 길이로 정합니다.** 더빙이 없으면 읽는 속도를 가정하므로, 말이 빠른 성우를 쓰면 장면이 짧게 느껴질 수 있습니다.

## 6. 실행·검사

정적 파일만으로 동작합니다. 로컬 서버로 열면 됩니다.

```bash
cd apps/clip-factory
python3 -m http.server 8080
# http://127.0.0.1:8080/
```

```bash
node test.js          # 단위 테스트 + 개인정보/외부요청 위생 검사 (404개 확인)
python3 uitest.py     # 헤드리스 Chrome E2E 152개 확인, preview-*.png 저장
```

배포된 사이트를 그대로 검사하려면 `UITEST_BASE=https://marcj81.github.io/onetap-clip-factory` 를
넘겨 같은 스위트를 라이브 URL에 돌립니다(로컬 서버를 띄우지 않습니다).

`uitest.py`는 1440×900과 390×844에서 콘솔 에러 0, 외부 요청 0, 가로 넘침 0을 확인하고,
데모 VOD 생성 → 분석 → 9:16 프리뷰(추적·자막) → 스토리 구간 추천(모의 AI·로컬 폴백) → 클립 적용 →
해설 자막 편집 · 자막 모드 3종 프리뷰 차이 → 실제 MP4 렌더(파일 헤더·크기·해상도·길이) → ZIP → 자막 편집 → AI 훅 모의 응답까지 검사합니다.
실측(이 개발 환경, 헤드리스 Chrome):
- 데모 32초 생성 + 분석: 약 14~16초 (인코딩 + 무음/컷 분석 + 추적 곡선 + 썸네일)
- 7초 스토리 클립 1080×1920 렌더(해설+대사 번인): 약 9~10초
- 7초·7초·4.8초 스토리 클립 720×1280 3개 렌더: 약 19초
- 결과 크기: 1080p 7초 ≈ 2.3MB, 720p 7초 ≈ 1.4MB

## 7. 프라이버시

- 영상·음성 서버 전송 0건, 첫 화면 외부 요청 0건. 폰트·라이브러리 모두 로컬.
- 영상·음성·자막 파일은 브라우저 밖으로 나가지 않습니다.
- 무료 AI 맛보기(`free-ai-taste.onetap-ai.workers.dev`)를 누를 때만 자막에서 뽑은 텍스트(대사 + 시간), 클립 길이, 원본 파일 이름, 무작위 방문자 식별자가 전송됩니다. 자세한 내용은 `privacy.html`.
- Pro 키는 sessionStorage(선택 시 localStorage)에만 저장되고, 연결한 제공자에게 브라우저에서 직접 요청합니다.
- 광고·분석·쿠키 없음.
